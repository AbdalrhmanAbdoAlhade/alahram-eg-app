# 🚀 ALAHRAM-EG-APP - نظام إدارة الخدمات والتجارة الإلكترونية API

مرحباً بك في مشروع **ALAHRAM-EG-APP**! هذا المشروع هو واجهة برمجية متكاملة (API) مبنية على **Laravel** لإدارة نظام تجارة إلكترونية وخدمات متكامل، يدعم المصادقة باستخدام **Laravel Sanctum** لإدارة المستخدمين وحماية المسارات الخاصة.

---

## 🌟 الميزات الأساسية

* **المصادقة:** تسجيل الدخول، التسجيل، تحديث الملف الشخصي، وتغيير كلمة المرور عبر Sanctum.
* **المنتجات والخدمات:** إدارة كاملة للمنتجات، الفئات، الماركات، الخدمات، والمراجعات.
* **الطلبات والمدفوعات:** إنشاء وتتبع وإدارة الطلبات، ودعم لدمج بوابات الدفع.
* **التسويق والإعلانات:** إدارة لافتات العرض (Banners) والعروض الخاصة (Offer Banners) وكوبونات الخصم.
* **إدارة المحتوى:** إدارة معلومات المتجر، سياسات الخصوصية، الإرجاع، ومعلومات الشحن.

---

## 🛠️ المتطلبات الأساسية

* **PHP:** الإصدار 8.1 أو أحدث.
* **Composer:** مدير الحزم الخاص بـ PHP.
* **Laravel:** الإصدار 10 أو أحدث.
* **قاعدة بيانات:** MySQL أو PostgreSQL.
* **Postman/Insomnia:** لاختبار واجهات API.

## ⚙️ دليل الإعداد والتشغيل

اتبع الخطوات التالية لإعداد المشروع وتشغيله محليًا:

### 1. استنساخ المشروع
```bash
git clone [رابط مستودع Git الخاص بك]
cd alahram-eg-app
```

### 2. تثبيت التبعيات (Dependencies)
```bash
composer install
```

### 3. إعداد ملف البيئة (.env)
قم بنسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
php artisan key:generate
```

ثم قم بتعديل إعدادات `DB_` في ملف `.env` لتناسب بيئتك المحلية.

### 4. ترحيل قاعدة البيانات (Migrations)
```bash
php artisan migrate
```

### 5. ربط التخزين (Storage Link)
```bash
php artisan storage:link
```

### 6. تشغيل خادم Laravel
```bash
php artisan serve
```
يمكنك الآن الوصول إلى واجهات API عبر العنوان:
```
http://127.0.0.1:8000/api/...
```

## 🔑 المصادقة (Authentication)
يتم حماية المسارات الخاصة باستخدام Laravel Sanctum.

### أهم المسارات:
| الغرض | المسار (URI) |
|-------|--------------|
| تسجيل الدخول | `/login` |
| التسجيل | `/register` |
| تسجيل الخروج | `/logout` |

### كيفية استخدام Token:
يتم إرسال الرمز المميز في رأس الطلب (Request Header) كالتالي:
```
Authorization: Bearer <Token_الذي_حصلت_عليه>
```

## 🌐 قائمة مسارات API الرئيسية
جميع المسارات تبدأ بـ `/api`.

### 1. المسارات العامة (Public Routes - GET فقط)
| المورد | مثال المسار | الغرض |
|--------|--------------|--------|
| الفئات/الماركات | `/api/categories`, `/api/brands` | جلب القوائم والعرض التفصيلي |
| المنتجات | `/api/products` | جلب قائمة المنتجات وعرض منتج واحد |
| البانرات/العروض | `/api/banners`, `/api/offer-banners` | عرض لافتات العرض والكوبونات |
| السياسات | `/api/privacy-policy`, `/api/shipping-info` | عرض صفحات معلومات المتجر |

### 2. المسارات المحمية (Protected Routes - CRUD)
هذه المسارات تتطلب المصادقة:

| المورد | العمليات |
|--------|-----------|
| الخدمات | CRUD كامل `/api/services` |
| الطلبات | إنشاء، عرض طلبات المستخدم، تحديث الحالة `/api/orders` |
| إدارة المنتجات | POST, PUT, DELETE `/api/products` |
| تحديث المحتوى | `/api/store-info/{id}`, `/api/about-us/{id}` |

**مثال لتحديث صورة المنتج:**
```
POST /api/products/update/{id}
```
